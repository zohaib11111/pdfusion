Before you install, ensure your system meets the following requirements:

## 📑 Features

pdfusion offers several useful features:

- **Text Extraction:** Easily extract text from PDF files for editing.
- **Image Processing:** Convert images in PDFs to separate files for easier use.
- **Table Reconstruction:** Transform complex tables into simple Markdown.
- **Intuitive UI:** User-friendly interface designed for everyone, regardless of technical skill.

## 🌐 How to Use pdfusion

1. Launch the application after installation.
2. Click the "Open PDF" button to select the file you want to convert.
3. Choose the desired output format—Markdown.
4. Click "Convert."
5. Save the new Markdown file to your preferred location.
